# Universal Keyboard

Android IME project for GitHub Actions builds.

Features include a gray keyboard background, white keys, black text, gray pressed keys with light-gray text, white popups with green selected popup keys, multilingual layouts, symbols, emoji, custom keyboard creation, and a unified Sumero-Akkadian cuneiform layout.

Cuneiform support is a Unicode input layout with basic educational reading mappings, not a complete historical dictionary.

This project intentionally does not include `gradle-wrapper.jar`. GitHub Actions installs Gradle 8.7 using `gradle/actions/setup-gradle@v6`.

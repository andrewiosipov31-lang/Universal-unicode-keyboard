# Universal Keyboard

Android IME-проект для сборки через GitHub Actions.

## Внешний вид
- серый фон раскладки;
- белые клавиши с чёрным текстом;
- при нажатии обычной клавиши она становится серой, текст — светло-серым;
- popup-клавиши имеют белый фон, а выбранная popup-клавиша — зелёный фон с белым текстом.

## Раскладки
Русский, украинский, белорусский, болгарский, казахский (кириллица/латиница), сербский (кириллица/латиница), узбекский (кириллица/латиница), польский, испанский, немецкий, греческий, универсальная латиница, English US, символы, эмодзи и шумерско-аккадская клинопись.

Клинопись предназначена как единая Unicode-раскладка для знаков и базовых учебных соответствий чтений шумерского/аккадского и родственных языков. Это не полный исторический словарь.

## Пользовательские клавиатуры
В приложении можно создать собственную раскладку. Введите название и строки, разделяя клавиши пробелами.

## Сборка без gradle-wrapper.jar
В проекте намеренно нет `gradle-wrapper.jar`. GitHub Actions устанавливает Gradle 8.7 через `gradle/actions/setup-gradle@v6`.

`gradlew` здесь — небольшой launch-скрипт, который скачивает Gradle 8.7 и запускает его. Это не официальный комплект Gradle Wrapper.
